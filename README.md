# Entropy Design System

A reusable design system foundation for the Entropy collaborative product UI.

## Overview

This project provides the design tokens and starter component primitives for the Entropy product experience. It is intended to be used as a shared foundation for the collaborative diagram editor, landing pages, authentication flows, and workspace surfaces.

## Included

- Theme tokens and palette definitions
- Typography rules
- Spacing and shadow scale
- Material UI theme overrides
- Starter reusable components

## Getting started

```bash
npm install
npm test
```

## Structure

```text
src/
  design-system/
    index.js
    theme.js
    components/
      Button.js
```

## Design direction

- Modern collaborative product aesthetics
- Clean neutral surfaces
- Bright green product accent
- Rounded, approachable UI blocks
- Soft depth and clear hierarchy
